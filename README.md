# 公众号封面生成与评选 Skill

一个用于 Codex 的公众号封面自动化 Skill。

提供文章、草稿、选题或本地文件后，它会一次完成：

> 读取文章 → 生成 10 张手绘公众号封面 → 检查并保存 → 按目标读者完整排名 → 推荐第一名

> 提示词来源：宝玉。本项目在该提示词基础上，将公众号封面生成、10 个候选方案和目标读者视角排名整理为可复用的 Codex Skill。

## 能做什么

- 根据文章内容自动提炼目标读者、核心观点和点击钩子
- 一次生成 10 张明显不同的公众号封面候选
- 统一采用 2.35:1 微信公众号封面比例
- 默认使用高对比手绘插画风格
- 标题控制在 8 个字以内，可加入一行副标题
- 从目标客户或目标读者视角给出完整第 1–10 名
- 解释每张图的优势、不足和可能误解
- 推荐最适合发布的第一名，并说明第二、第三名的适用场景

## 适用场景

- 微信公众号文章封面
- 微信文章头图与内容配图
- 商业观点、知识科普、职场成长、教育、科技和生活类文章
- 需要一次获得多个视觉方案并进行选择
- 需要从目标客户、读者兴趣和点击吸引力角度评选封面

## 安装

### 方法一：复制目录

将本仓库复制到 Codex 个人 Skill 目录：

```bash
git clone https://github.com/HeyClioo/wechat-article-cover-skill.git
cp -R wechat-article-cover-skill "$HOME/.codex/skills/wechat-article-cover"
```

### 方法二：使用安装包

下载 [`dist/wechat-article-cover.skill`](dist/wechat-article-cover.skill)，通过支持 `.skill` 文件的 Codex 环境安装。

## 使用方法

把文章文件路径或正文交给 Codex：

```text
使用 wechat-article-cover，根据这篇文章生成 10 张公众号封面，并按目标读者吸引力完整排名：
/你的路径/文章.md
```

也可以直接说：

```text
根据这篇文章生成十张公众号封面，给出完整排名和原因：
【粘贴文章正文】
```

默认会直接生成 10 张候选并排名，不需要分三轮下达指令。

## 默认封面规范

- 手绘插画风格，避免写实和混合风格
- 2.35:1 公众号标准横幅比例
- 主视觉居中或偏左，右侧保留标题区域
- 1–2 个简洁卡通形象、图标或原创人物剪影
- 大量留白，保证手机缩略图清楚
- 标题醒目且不超过 8 个字
- 使用悬念、数字、痛点或视觉反差增强点击欲望
- 默认中文，使用橙黄、蓝紫、红黑等高对比配色

完整执行规则见 [SKILL.md](SKILL.md)。

## 说明

- 封面排名是基于内容、视觉和目标读者的策略判断，不代表已经验证的真实点击率。
- 中文文字由图片模型直接生成时仍可能出现错字，Skill 会检查明显问题并尝试重新生成。
- 涉及真人、知名人物或受保护角色时，默认使用不模仿具体对象的原创替代形象。
